# Design

Status: `CURRENT LIVE V2 / REVAMP HELD / NO PRODUCTION`

> 아래 디자인·카피는 현재 라이브 기준이다. 2026-08-12 리브랜딩 개편은 대표 결정으로 실제 제작하지 않으며 새 제작 기준으로 사용하지 않는다. 재개에는 새 명시 요청과 새 `APPROVED` 브리프가 필요하다.

## 방향

시각 목표는 `실전형 외부 마케팅 파트너`다. 화려한 대행사 소개나 포토그래퍼 포트폴리오처럼 보이지 않게 하고, 대표가 빠르게 문제와 맡길 범위를 읽게 한다.

## 첫 화면

- 문제: `마케팅은 계속하는데 어디부터 손봐야 할지 모르겠다면`
- 약속: `사업에 필요한 콘텐츠의 우선순위를 정하고 제작과 운영까지 맡습니다.`
- CTA: `마케팅 상담하기`
- 보조 요청: 업종, 운영 채널, 가장 막힌 일 두세 줄

## 시각 원칙

- 짙은 차콜 바탕과 보라색을 핵심 색으로 쓴다.
- 생성된 오로라 파동 이미지는 분위기와 방향감을 만들되 텍스트 대비를 해치지 않는다.
- 큰 제목, 얇은 경계선, 넓은 여백으로 편집물처럼 구성한다.
- 반복 카드 장식보다 번호와 실제 문장을 사용한다.
- 버튼은 실색으로 또렷하게 만들며 노란색은 작은 카카오 아이콘 강조에만 쓴다.
- 데스크톱의 2열 설명은 모바일에서 자연스럽게 1열로 바뀐다.

## 카피 원칙

- `브랜드 가치`, `통합 솔루션`, `성장 생태계` 같은 과장어를 쓰지 않는다.
- `네이버`는 공개하지 않고 `국내 포털`로 표현한다.
- 실제 작업 범위만 말하며 결과 수치를 추정하지 않는다.
- 채널명을 길게 나열하기 전에 대표가 겪는 장면을 보여준다.
- 짧고 현장에 가까운 문장으로 쓴다.

## 상호작용·접근성

- 헤더는 스크롤 시 경계만 강화한다.
- FAQ는 네이티브 `<details>`를 사용한다.
- 모든 핵심 CTA는 키보드로 접근 가능하고 44px 이상 터치 영역을 갖는다.
- `prefers-reduced-motion`을 존중한다.
- JavaScript가 실패해도 본문과 FAQ가 보인다.
- 모바일 390px에서 가로 스크롤과 잘린 제목이 없어야 한다.

## 비목표

- 추상적인 브랜드 철학 중심 페이지
- 인물 사진 중심의 포트폴리오
- 자동 재생 영상이나 무거운 캔버스 애니메이션
- 사용자가 정하지 않은 가격·성과 수치 표시
