# Design

## Source of Truth

상세 카피, 섹션 구조, 현재 히어로 방향은 `../prd.md`를 원본으로 한다.

이 문서는 AI 작업자가 디자인과 카피 맥락을 빠르게 확인하기 위한 지도다.

## Brand Direction

오로라의소리는 콘텐츠 방향 설계와 채널 구조 컨설팅을 다루는 서비스다. 랜딩은 화려한 기능 설명보다, 방문자가 자신의 채널 문제가 어디서 막혔는지 느끼고 상담으로 넘어가게 만드는 흐름을 우선한다.

## Current Hero Direction

- Main hook: `유튜브가 문의로 이어지지 않는다면`
- Supporting copy: 영상 문제가 아니라 고객이 문의할 이유가 막힌 지점을 짚는다.
- CTA: 카카오톡으로 이유를 물어보게 유도한다.
- 첫 3카드: 메시지 부재, 약한 CTA, 끊긴 채널 흐름

## Visual Principles

- 오로라 캔버스 배경은 히어로의 분위기를 만들되 카피를 방해하지 않는다.
- CTA는 상담 행동으로 명확히 연결되어야 한다.
- 섹션은 문제 인식에서 이유 진단, 해결 관점, 후기, FAQ, 최종 CTA로 흐른다.
- 모바일에서 가로 스크롤이 생기면 실패로 본다.
- 광고 경로와 오가닉 경로의 화면은 같게 유지한다.

## Interaction Principles

- 아코디언, 스크롤, 플로팅 버튼은 가벼워야 한다.
- CTA id는 analytics 이벤트와 연결되어 있으므로 시각 수정 때도 보존 여부를 확인한다.
- 외부 링크 변경은 추적 이벤트와 같이 확인한다.

## Non-goals

- 정식 홈페이지 수준의 다중 페이지 정보 구조
- 루트와 `/interview`의 화면 분리
- 설명이 긴 컨설팅 소개 페이지
- 추적 구조를 깨는 CTA 재배치

## Update Rules

히어로 카피, CTA 문구, 섹션 순서, 모바일 레이아웃 기준이 바뀌면 `prd.md`, `docs/DESIGN.md`, `README.md`의 관련 메모를 함께 확인한다.
