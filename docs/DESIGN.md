# Design

## Source of Truth

상세 카피, 섹션 구조, 현재 히어로 방향은 `../prd.md`를 원본으로 한다.

이 문서는 AI 작업자가 디자인과 카피 맥락을 빠르게 확인하기 위한 지도다.

## Brand Direction

오로라의소리는 이미 운영 중인 홈페이지·콘텐츠·광고를 놓고 다음 한 달의 우선순위와 실행 기준을 정하는 외부 마케팅팀이다. 랜딩은 채널별 기능 설명보다, 진단 미팅 뒤 대표가 무엇을 가져가는지 먼저 보여주고 상담으로 넘어가게 만드는 흐름을 우선한다.

## Current Hero Direction

- Target: `이미 마케팅을 운영 중인 전문직과 소규모 사업자`
- Main hook: `다음 한 달의 우선순위를 정합니다`
- Supporting copy: 현재 하는 일을 놓고 먼저 고칠 일과 실행 순서를 정한다고 설명한다.
- CTA: `한 달 우선순위 진단받기`
- 첫 3카드: 이번 달 우선순위, 수정 기준, 파트너 판단
- 첫 문장 시연: 상품 전체를 대표하지 않고 오로라의 판단 방식을 보여주는 증거로 둔다.

## Visual Principles

- 오로라 캔버스 배경은 히어로의 분위기를 만들되 카피를 방해하지 않는다.
- CTA는 상담 행동으로 명확히 연결되어야 한다.
- 섹션은 대상과 약속, 미팅 결과, 진단 방식, 판단 시연, 적합한 고객, 대표의 근거, FAQ, 최종 CTA로 흐른다.
- 모바일에서 가로 스크롤이 생기면 실패로 본다.
- 광고 경로와 오가닉 경로는 같은 핵심 랜딩을 보여준다. 다만 `/interview`에서는 상담 집중을 위해 WordPress 블로그 보조 CTA와 푸터 채널 링크를 숨긴다.

## Interaction Principles

- 아코디언, 스크롤, 플로팅 버튼은 가벼워야 한다.
- CTA id는 analytics 이벤트와 연결되어 있으므로 시각 수정 때도 보존 여부를 확인한다.
- 외부 링크 변경은 추적 이벤트와 같이 확인한다.

## Non-goals

- 정식 홈페이지 수준의 다중 페이지 정보 구조
- 루트와 `/interview`의 핵심 카피·섹션 분리
- 설명이 긴 컨설팅 소개 페이지
- 추적 구조를 깨는 CTA 재배치

## Update Rules

히어로 카피, CTA 문구, 섹션 순서, 모바일 레이아웃 기준이 바뀌면 `prd.md`, `docs/DESIGN.md`, `README.md`의 관련 메모를 함께 확인한다.
