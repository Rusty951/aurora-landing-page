# 홈페이지 V1 포트폴리오

현재 목록의 원본은 work/catalog.json이다. 공개 47개 카드에는 Photo의 다섯 모음, Concepts 34개와 Website 8개가 포함된다. 이미지 및 샘플 소스는 이 저장소의 work/assets 및 work/demos에 보관한다.

## Photo

대표가 직접 제작한 사진과 비주얼 41장을 Product 11장, Food 9장, Dessert 6장, Space 4장 및 Portrait 11장의 모음으로 제공한다. 촬영 확인, 파일 해시와 원본 식별은 docs/PORTFOLIO-SOURCES.json을 따른다. 별도 제작 브랜드 표기를 붙이지 않는다. 공개 목록과 확대 화면은 현재 운영한 41장을 유지하며 추가 원본을 자동 공개하지 않는다.

## Concepts

자체 제작과 AI 시안 34개다. AI 푸드 및 제품 비주얼, 브랜드 장면, 8장 인스타 캐러셀과 찰리, 페니 및 버디의 시리즈를 포함한다. 출처와 생성 정보는 docs/PORTFOLIO-SOURCES.json 및 docs/PORTFOLIO-PROMPTS.json을 보존한다. 시안과 촬영, 가상 사례를 구별하고 고객 납품이나 성과를 추정하지 않는다.

## Website

현재 샘플은 Formkey, NOCTE, SEAM, Banana Black, 서래커튼, 수집노트, 스위치조명과 법률사무소 서안이다. 샘플 원본은 Rusty951/aurora-website-portfolio에서 가져온 독립 디자인이며 현재 홈페이지에서 쓰는 사본은 work/demos 안에 있다. 원본 저장소의 별도 리뉴얼은 이 홈페이지의 과거 버전이 아니다. 이후 대표가 요청하면 선정한 변경을 반영한다.

분류는 Website, Concepts, Photo 순이고 첫 진입은 Website다. Website는 Signature와 Essential 구분을 합쳐 여덟 작업을 한 목록으로 제공한다. 순서는 Formkey, NOCTE, SEAM HOTEL, 스위치조명, 서래커튼, 법률사무소 서안, 수집노트와 Banana Black이다. 분야와 가상 샘플 또는 보관본 여부를 카드에 표시한다. PC 두 열과 모바일 한 열, 1440×810 대표 이미지 및 높낮이와 스크롤 모션을 사용한다. 공개된 데모는 가상 사업체의 시연이며 예약과 문의가 외부로 전송되지 않는다. 각 데모의 SOURCES.md와 README.md는 출처 기록으로 보관하되 운영 배포에서 제외한다.

## 이용 조건과 화면

원본 출처 JSON과 이미지 해시, 생성 정보, 폰트 및 스톡 라이선스 기록은 현재 자료의 일부다. 홈페이지 이전 시안을 정리하면서 함께 지우지 않는다. 공개 목록은 static fallback으로도 읽을 수 있으며 확대는 원래 이미지 비율, 닫기와 초점 복귀, 좌우와 방향키 및 터치 탐색을 지원한다. 운영 footer의 Disclaimer와 법적 문서 내용은 유지한다.

## 2026-10-05 샘플 관리 통합

샘플 원본은 ../aurora-website-portfolio 하나다. work/demos는 npm run sync:samples로 생성하는 배포용 사본이며 직접 수정하지 않는다. NOCTE와 SEAM의 원본은 변경하지 않는다. 병원4개와 디자인플레아 자료는 오로라 배포 사본에 포함하지 않는다. Photo41장 및 Concepts34개는 정리 대상이 아니다. 이번 작업은 로컬 정리이며 운영 배포는 별도다.

## 2026-10-08 서안 마감본 반영

법률사무소 서안만 정본0c5beb9의 v58.2로 갱신했다. 선택 반영은 `npm run sync:samples -- --route=13-chaon-law`를 사용한다. 선택하지 않은 데모와 기존 공유 파일은 유지하고, 지정하지 않으면 기존 전체 동기화 방식이 동작한다. 목록 썸네일과 상세의 PC1440×810/모바일390×844 캡처는 실제 갱신된 사본에서 다시 촬영했다. 이미지 주소의 캐시는58.2로 바꾸고 상세/샘플의 기존 공개 경로를 유지한다.

## 2026-10-08 일반4개 전체 최신본 반영

앞선 반영이 서안에만 적용되어 나머지 일반3개가 이전 상태였던 범위를 바로잡았다. 선택 동기화로 서래커튼 v55.1, 수집노트 v56.1, 스위치조명 v57.2를 추가 반영했고 서안 v58.2와 함께 일반4개를 정본0c5beb9에 맞췄다. 세 사이트의 실제 사본에서 PC1440×810/모바일390×844를 새로 캡처해 목록/상세/OG 이미지를 갱신했다. 각 주소의 캐시는 해당 버전을 사용한다. Signature와 나침반의 병원 샘플은 이번 변경 대상이 아니다.

사용자 요청에 따라 Formkey, NOCTE, SEAM HOTEL, 스위치조명, 서래커튼, 법률사무소 서안, 수집노트, Banana Black 순으로 재배치했다. PC 첫 두 줄은 붉은 그래픽/숲 장면, 호텔 공간/조형 조명으로 묶었다. 모바일도 같은 순서로 이어진다. 목록과 카탈로그만 재배치하고 원본 이미지와 개별 샘플을 유지한다.

## 2026-10-08 작업 설명 보완

웹사이트8개 상세의 작업 설명을 각각 세 문단으로 확장했다. 방문자가 확인할 내용, 실제 화면에서 택한 이미지와 글의 역할, 다음 행동으로 이어지는 구성을 각 작업의 소재에 맞춰 설명한다. Formkey는 기능 체험, NOCTE는 향을 상상하는 장면, SEAM은 공간의 이동과 객실 확인, 조명과 커튼은 선택 정보, 서안은 첫 상담 준비, 수집노트는 읽는 리듬, Banana Black은 촬영물 탐색과 보관본의 성격을 다룬다. 가상 브랜드를 실제 고객 사례로 표현하거나 조사, 성과와 방문자 반응을 추가하지 않는다.
