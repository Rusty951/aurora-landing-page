# 브랜드 노트 운영과 편집 기준

2026-10-11 대표가 기존 첫 화면을 유지한 대표 작업 교체와 브랜드 노트 세 편의 정식 공개를 요청했다. 브랜드 노트는 기존 홈페이지 디자인 안에서 포트폴리오와 상담으로 이어지는 콘텐츠다. Firebase 전환은 이번 범위에 포함하지 않는다.

2026-10-14 표시 이름을 브랜드 노트로 변경했다. 공통 헤더는 포트폴리오, 브랜드 노트, 함께하는 일 순서다. 기존 /journal 주소와 글 식별자 및 생성 파일명은 유지한다.

## 구조와 운영

- `/journal`: 추천 글 하나와 나머지 글 목록.
- `/journal/<slug>`: 제목과 요약, 이미지, 목차와 본문, 적용 질문, 관련 작업, 관련 업무와 상담, 이어 읽기.
- 홈페이지: 대표 작업 아래 브랜드 노트 미리보기.
- 연결된 포트폴리오: 작업 설명 뒤 해당 판단을 읽는 브랜드 노트 링크.
- 상담: 기존 `/#contact` 안내를 거쳐 기존 카카오 목적지로 이동한다. 새 접수 서버나 자동 전송을 만들지 않는다.

브랜드 노트의 업종은 고정하지 않는다. 첫 상담, 서비스 이해, 콘텐츠와 문의처럼 고객의 문제를 기준으로 관련 작업을 직접 선택한다. 단순히 같은 업종이라는 이유만으로 연결하지 않는다.

`journal/articles.json`의 세 편은 검토 후 정식 공개하는 사이트 원고다. 법률사무소 서안, Formkey와 스위치조명 자체 제작 샘플의 판단을 설명한다. 고객 실적이나 문의, 매출 성과를 나타내지 않는다. 내용과 적용 질문, 관련 작업 및 상담 연결을 다시 확인했으며 이번 발행에서 본문을 불필요하게 다시 쓰지 않았다. 작성일 데이터는 내부에 보관하며 사이트 화면에는 표시하지 않는다. 페이지는 `index, follow`이며 목록과 세 글을 sitemap에 포함한다. 각 페이지에 고유 canonical과 공유 정보를 제공한다. 이후 새 원고는 기존 콘텐츠 원본 관리 흐름에서 작성하고 확정본만 이 사이트 데이터에 반영한다. 이 파일을 별도 발행 원장으로 쓰지 않는다.

대표의 최종 정정에 따라 업체가 가상이라는 설명은 본문에 넣지 않는다. 글 하단 푸터의 별도 편집 안내에서 한 번 밝힌다. 제목과 요약, 이미지 설명과 관련 작업 카드에도 반복하지 않는다. 본문은 이런 업종의 사업자가 이런 상황이라면 어떻게 구성할지 설명한다. 실제 고객 수행이나 성과 사례로 쓰지 않는다. 기존 포트폴리오 자체의 표시 계약은 유지한다.

외부 브랜드 분석 글도 같은 상세 템플릿을 사용할 수 있다. 관찰한 자료와 해석, 우리 사업의 적용 질문을 구분하고 원문 출처를 제공해야 한다. 관련 실제 작업이 없는 글에 가상의 수행 실적을 넣지 않는다.

## 생성과 확인

`npm run journal:build`로 정적 HTML을 생성한다. 목록과 상세, 홈페이지의 표시 구역, 포트폴리오의 역방향 연결은 같은 데이터를 읽는다. 홈페이지와 기존 작업 페이지 전체를 재생성하지 않고 표시된 브랜드 노트 구역과 공통 메뉴만 갱신한다. 폰트와 공유 헤더, 푸터는 기존 원본을 재사용한다. 이미지 원본을 복제하거나 변경하지 않는다.

`npm run dev` 후 `http://localhost:4173/journal`에서 확인한다. 브라우저 JavaScript가 없어도 글과 링크를 읽을 수 있다. WordPress, CMS, Firestore나 새 패키지 의존성을 추가하지 않았다. 현재 디렉터리 구조는 글별 `index.html`을 제공하며 향후 호스팅의 경로 처리 설정은 전환 작업에서 확인한다.

`npm run check`는 기존 검사에 브랜드 노트 생성 결과, 로컬 링크, 목차, 포트폴리오 연결과 상담 목적지 검사를 더한다. 실제 화면 검수는 `design-qa.md`를 따른다.

생성 스크립트는 목록과 세 글의 Vercel rewrite 및 sitemap 항목을 중복 없이 관리한다. 새 글도 승인 원고를 반영한 뒤 경로, 검색 설정과 포트폴리오 연결을 검사한다. 검색 설정의 완료와 실제 검색엔진 색인은 구분한다.

## 이미지와 서체

법률사무소 서안 이미지의 근거는 `work/demos/13-chaon-law/assets/SOURCES.md`, Formkey는 `work/demos/18-formkey-productivity/assets/SOURCES.md`, 홈페이지 스크린샷은 기존 `work/catalog.json`과 `docs/PORTFOLIO-SOURCES.json`을 따른다. 사진처럼 보이는 자체 생성 장면을 실제 사무소나 고객으로 설명하지 않는다.

기존 DM Sans, Asta Sans, Instrument Serif와 아리따 부리, 아리따 돋움을 그대로 사용한다. 본문은 아리따 부리 Medium 400, 한글 제목은 같은 서체의 SemiBold 600이다. 상세 본문은 PC 18px에 행간 1.85, 모바일 17px에 행간 1.8이며 제목 자간은 -0.025em이다. 목록과 홈페이지 카드 설명은 16px, 포트폴리오의 관련 글 설명은 16px에 행간 1.8이다. 작성 날짜는 목록, 상세와 홈페이지 미리보기에 표시하지 않는다. 폰트 원본과 기존 라이선스 고지를 유지한다.
