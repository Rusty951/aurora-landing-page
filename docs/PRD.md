# PRD

## Source of Truth

상세 제품 원본은 루트의 `prd.md`다.

이 문서는 AI 작업자가 제품 의도를 빠르게 잡기 위한 운영용 PRD 지도다. 제품 범위, URL 전략, 추적 정책이 바뀌면 `prd.md`, `README.md`, 이 문서를 함께 갱신한다.

## 문제

오로라의소리 서비스는 이미 마케팅을 운영 중인 대표에게 다음 한 달에 먼저 고칠 일, 직원·기존 업체에 전달할 수정 기준, 직접 할 일과 맡길 일을 1시간 진단 미팅의 결과로 보여줘야 한다.

루트와 광고 경로는 같은 핵심 랜딩을 보여주되 유입과 추적 맥락을 분리한다. 광고 경로에서는 상담 집중을 위해 일부 보조 이탈 링크만 숨긴다.

## 사용자

- 홈페이지·콘텐츠·광고 중 하나 이상을 실제로 운영 중인 전문직과 소규모 사업자
- 다음 한 달에 무엇부터 고칠지 못 정한 대표
- 직원이나 기존 업체에 전달할 수정 기준이 필요한 대표
- 광고 경로(`/interview`)로 유입된 잠재 상담 고객
- 오가닉 경로(`/`)로 유입된 대표 방문자

## 목표

- 루트 `/`와 `/interview`에서 같은 핵심 랜딩을 안정적으로 서빙한다.
- CTA 클릭을 GA4와 Meta Pixel 맥락에 맞게 추적한다.
- 사용자가 카카오톡으로 업종, 운영 중인 채널, 가장 막힌 일을 보내고 진단 미팅을 문의하게 유도한다.
- 정식 홈페이지 전환 전까지 랜딩 중심 정보 구조를 유지한다.
- 모바일에서 카피와 CTA가 깨지지 않게 유지한다.

## MVP 범위

- `index.html` 공통 랜딩
- `privacy.html` 개인정보처리방침
- `terms.html` 서비스 이용약관
- `/interview` rewrite
- GA4 이벤트 추적
- `/interview` 한정 Meta Pixel 추적
- 카카오톡 CTA
- 로컬 정적 서버

## 비목표

- 정식 홈페이지 정보 구조 완성
- 프레임워크 도입
- 서버/API 구축
- 루트와 광고 경로의 핵심 카피·섹션 분리
- 추적 ID/Pixel 정책의 무승인 변경

## 성공 기준

- `/`와 `/interview`가 같은 핵심 랜딩을 보여준다.
- `/interview`에서는 WordPress 블로그 보조 CTA와 푸터 채널 링크만 숨긴다.
- 운영 도메인의 `/interview` 경로에서만 Meta Pixel이 실행된다.
- CTA 클릭 이벤트가 GA4와 Meta Contact 조건에 맞게 발송되며 실제 유효 문의와 구분된다.
- 실제로 보이는 탭의 누적 열람 10초를 `engaged_10s`로 랜딩 경로별 세션당 한 번 기록한다.
- 수정 후 캐시 버스팅 버전이 함께 갱신된다.
- 운영 문서가 Vercel 배포 표면에 노출되지 않는다.
