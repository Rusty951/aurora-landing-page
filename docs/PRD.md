# PRD Map

Status: `LIVE r2 / PRODUCTION VERIFIED`

상세 제품 원본은 루트 `prd.md`다. 제품 범위, URL, CTA, 추적 의미가 바뀌면 `prd.md`, `README.md`, 이 문서를 함께 갱신한다.

## 현재 로컬 제품

사업이 바뀌는 순간 고객에게 무엇으로 보일지 정하고 첫 콘텐츠와 우선 접점에 적용하는 `리브랜딩 실행 파트너` 랜딩이다.

- 주력 단건: `리브랜딩 실행 프로젝트`
- 별도 반복: `월간 브랜드 마케팅`
- 역할 경계: 콘텐츠 중심. 로고·UI·공간은 조건부, 경영 컨설팅은 기본 범위 아님
- 진행: 적합성 대화 → 범위 확정 → 기존 콘텐츠 점검 → 새 인식·기준 승인 → 첫 적용 → 인계·종료

## 핵심 사용자 상태

- 새 매장·서비스, 리뉴얼, 이전·확장, 가맹 전환처럼 변화 시점이 분명하다.
- 결정권자가 직접 참여한다.
- 기존 자료, 예산 범위, 착수 시점을 논의할 수 있다.
- 첫 콘텐츠와 우선 접점까지 실제 적용할 준비가 돼 있다.

월간 상품은 브랜드 방향과 승인권자가 정리된 뒤 반복 제작·배포·수정이 멈춘 경우에만 별도로 제시한다.

## 진입 행동

- 본문 CTA: `적합성 대화 요청하기`
- 모바일 헤더: `적합성 대화`
- 채널: 카카오 오픈채팅
- 첫 메시지: `리브랜딩 / 월간 / 기타`, 현재 상황, 확인 자료, 희망 시점

20~30분 대화에서는 변화 시점·결정권자·예산·자료·착수 가능성을 확인하고 다음 경로만 정한다. 무료 해결안·상세 진단·완성 카피를 제공하지 않는다.

## URL

- `/`: 대표·오가닉 랜딩
- `/interview`: 광고 랜딩
- `/interview/`: production 308 정규화
- 광고 경로는 비필수 footer 채널만 숨기고 핵심 카피·CTA를 유지한다.

## 증거 경계

첫 배포 후보는 상품 정의, 진행 순서, 책임 구조, 승인·제외 경계만 사용한다. 검증 전 경력, 타 클라이언트 사례, 고객명·후기·성과·가격은 넣지 않는다.

## 성공 기준

- 첫 화면에서 변화 시점, 오로라의 역할, 다음 행동이 함께 읽힌다.
- 두 상품이 한 계약처럼 섞이지 않는다.
- CTA 클릭과 실제 문의·적합 문의·제안·계약을 구분한다.
- 1440·390·320px, 키보드, 네이티브 FAQ에서 핵심 흐름이 동작한다.
- 운영 문서·OG 렌더 원본·검수 파일은 배포 표면에서 제외한다.
- 최종 변경본에 대한 명시적 공개 승인 전 production 배포하지 않는다.
