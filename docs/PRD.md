# PRD

## Source of Truth

상세 제품 원본은 루트의 `prd.md`다.

이 문서는 AI 작업자가 제품 의도를 빠르게 잡기 위한 운영용 PRD 지도다. 제품 범위, URL 전략, 추적 정책이 바뀌면 `prd.md`, `README.md`, 이 문서를 함께 갱신한다.

## 문제

오로라의소리 서비스는 콘텐츠 방향 설계와 채널 구조 컨설팅의 가치를 빠르게 설명하고, 방문자가 카카오톡 상담으로 넘어갈 이유를 만들어야 한다.

루트와 광고 경로가 같은 랜딩을 보여주므로, 화면은 같아도 유입과 추적 맥락은 분리되어야 한다.

## 사용자

- 유튜브나 채널 운영이 문의로 이어지지 않아 고민하는 사람
- 콘텐츠 방향과 메시지 구조를 정리하고 싶은 1인 브랜드/사업자
- 광고 경로(`/interview`)로 유입된 잠재 상담 고객
- 오가닉 경로(`/`)로 유입된 대표 방문자

## 목표

- 루트 `/`와 `/interview`에서 같은 랜딩을 안정적으로 서빙한다.
- CTA 클릭을 GA4와 Meta Pixel 맥락에 맞게 추적한다.
- 사용자가 카카오톡으로 상담 이유를 물어볼 수 있게 유도한다.
- 정식 홈페이지 전환 전까지 랜딩 중심 정보 구조를 유지한다.
- 모바일에서 카피와 CTA가 깨지지 않게 유지한다.

## MVP 범위

- `index.html` 공통 랜딩
- `privacy.html` 개인정보처리방침
- `/interview` rewrite
- GA4 이벤트 추적
- `/interview` 한정 Meta Pixel 추적
- 카카오톡 CTA
- 로컬 정적 서버

## 비목표

- 정식 홈페이지 정보 구조 완성
- 프레임워크 도입
- 서버/API 구축
- 루트와 광고 경로의 화면 분리
- 추적 ID/Pixel 정책의 무승인 변경

## 성공 기준

- `/`와 `/interview`가 같은 랜딩을 보여준다.
- `/interview` 경로에서만 Meta Pixel이 실행된다.
- CTA 클릭 이벤트가 GA4와 Meta Lead 조건에 맞게 발송된다.
- 수정 후 캐시 버스팅 버전이 함께 갱신된다.
- 운영 문서가 Vercel 배포 표면에 노출되지 않는다.
