# Landing V2 Renewal Brief

## 목적

기존 랜딩은 1시간 진단과 다음 한 달의 우선순위를 최종 상품처럼 보여줬다. V2는 오로라의 실제 역할인 `필요한 콘텐츠를 정하고 제작·운영까지 맡는 외부 실행 파트너`를 첫 화면부터 판매한다.

## 타깃 상태

업종보다 현재 상태로 정의한다.

- 이미 마케팅을 하고 있다.
- 여러 채널이나 업체가 따로 움직인다.
- 대표가 우선순위와 요청 기준을 계속 결정한다.
- 무엇을 먼저 고칠지 몰라 발행만 이어진다.
- 판단 뒤 실제 제작과 운영을 맡길 파트너가 필요하다.

## 확정 메시지

- H1: `마케팅은 계속하는데 어디부터 손봐야 할지 모르겠다면`
- 약속: `사업에 필요한 콘텐츠의 우선순위를 정하고 제작과 운영까지 맡습니다.`
- CTA: `마케팅 상담하기`
- 경력: `국내 포털 콘텐츠 매니저 출신`

`네이버` 회사명, `무료`, 검증되지 않은 성과 수치, 과장된 `브랜드` 표현은 공개하지 않는다.

## 서사

1. 방문자의 혼란을 짚고 오로라의 실행 책임을 말한다.
2. 채널·대표·문의 경로가 따로 움직이는 실제 상황을 보여준다.
3. 오로라가 우선순위·메시지·제작·운영을 어떻게 맡는지 설명한다.
4. 상담을 `설명 듣는 자리`가 아니라 일을 시작하는 과정으로 둔다.
5. 공개 가능한 경력과 익명 사례로 범위를 증명한다.
6. 맞는 고객과 주력하지 않는 일을 분리한다.
7. FAQ에서 기존 직원·업체와 병행 가능하고 상담 뒤 강제 계약이 없음을 답한다.
8. 같은 문구의 카카오 CTA로 마친다.

## 시각 방향

- 선택안: 세 시안 중 1안
- 톤: 어두운 편집물, 보라색 파동, 선명한 큰 제목
- 자산: 생성된 오로라 배경 이미지를 히어로와 최종 CTA에 사용
- UI: 얇은 선, 번호형 목록, 단순한 아이콘, 네이티브 FAQ
- 제거: 캔버스 애니메이션, 숨겨진 fade-up, 플로팅 CTA, 커스텀 아코디언

## 신뢰 근거 경계

공개 가능한 확인 범위만 사용한다.

- 국내 포털 콘텐츠 매니저 출신
- 인테리어 업체: 여러 채널과 문의 경로 정리
- 치킨 프랜차이즈 가맹 모집: 예비 점주 질문 기준 콘텐츠 순서 구성
- 병원 블로그: 의료진 설명을 환자가 이해하는 순서로 정리

성과 수치, 고객명, 회사명은 확인·승인 전까지 추가하지 않는다.

## 기술·분석

- `/`, `/interview` 공통 HTML
- `/interview/` → `/interview` 정규화
- HTML `data-track` 기반 단일 이벤트 위임
- 광고 경로 Meta PageView 1회
- 카카오 외부 링크는 Meta `Contact`, 실제 문의는 별도 단계
- 정적 계약 검사와 시각 QA를 모두 통과한 뒤 공개 승인 요청

## 공개 전 남은 판단

- 상담 가격·기간·산출물 공개 여부
- 실제 작업 화면 또는 고객 사례 공개 범위
- 쿠키·분석 동의 방식에 대한 별도 법률 검토

이 항목은 추정해서 채우지 않으며, 랜딩 V2 공개를 막는 기술 결함과는 분리해 후속 결정한다.
