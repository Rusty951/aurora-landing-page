# NOCTE, five moments

Version 12. 가상 향수 브랜드의 풀스크린 스크롤 포트폴리오다. Garden → Bloom → Touch → Essence → Echo의 다섯 장면으로 구성한다. 실제 상품 판매나 고객 프로젝트가 아니다.

## 현재 작업 위치

2026-10-04부터 이 폴더를 NOCTE의 수정 정본으로 사용한다. 선택한 v12 HTML, CSS, JavaScript와 사용 자산을 기존 제작 폴더에서 가져왔다. 향수 이미지, 영상, 음악, 폰트와 각각의 라이선스를 포함한다. 화면 문구, 스크롤 타이밍, 제목 모션과 가로 화면 수정을 그대로 유지한다.

저장소 루트에서 다음 명령으로 실행한다.

```sh
python3 -m http.server 8770 --bind 127.0.0.1
```

- 포트폴리오 허브: http://127.0.0.1:8770/
- NOCTE: http://127.0.0.1:8770/15-nocte/?v=12#garden

별도 설치나 빌드가 필요 없는 정적 HTML/CSS/JavaScript다. CSS와 JavaScript 캐시 키는 12다. 영상, 이미지, 음악과 폰트를 모두 로컬 파일로 제공한다.

## 구성과 조작

스크롤로 다섯 장면을 진행한다. Touch의 손동작은 스크롤 위치에 연결되고, 꽃에 닿은 뒤 병이 먼저 드러나고 문구가 뒤따른다. Essence는 선택한 향수 사진에 CSS 모션을 적용한 장면이다.

장면 탐색 메뉴, 다음 버튼, Home/End와 PageUp/PageDown, 움직임 정지와 재생, About 팝업을 제공한다. Garden의 진입 버튼은 Bloom으로, Echo의 재시작 버튼은 Garden으로 연결된다. 화면 높이가 낮은 가로 화면에서는 헤더와 메뉴 사이에 본문 공간을 확보한다.

음악은 기본으로 꺼져 있다. 사용자가 켜면 Scott Buckley의 Reverie를 낮은 볼륨과 페이드로 재생한다. 음악 버튼과 화면 움직임 제어는 별도다. About에 가상 브랜드 설명, 제작 범위와 자산 크레딧이 있다.
