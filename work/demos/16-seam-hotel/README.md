# SEAM

가상의 해안 디자인 호텔을 걸어보는 새 웹 포트폴리오. 기존 `15-nocte/`와 별개다.

## 경험

접근로, 중정, 로비와 통로, 객실, 테라스로 이어진다. Blender로 만든 하나의 고정된 공간에서 카메라가 1.62m 눈높이로 이동한다. 웹에서는 스크롤 위치를 공통 진행률로 바꿔 그에 해당하는 렌더 프레임을 표시한다. 멈추면 짧은 보간 뒤 정지하고, 역방향으로 스크롤하면 같은 동선의 앞 프레임을 표시한다.

영상은 로컬 3D 건축 모션 시안이다. 실제 호텔 촬영이나 생성형 실사 영상으로 소개하지 않는다. 24초 이동과 마지막 프레임을 포함한 481개 렌더를 사용한다. 같은 소스에서 무음 MP4도 내보낸다. 프레임 시퀀스는 브라우저의 영상 탐색 지연과 역방향 탐색 편차를 피하기 위한 표시 방식이다.

화면에서는 현재와 인접 프레임만 준비하고, 디코딩한 비트맵의 캐시는 최대 18개로 제한한다. 표시 중인 프레임의 참조가 끝나기 전에 비트맵을 강제로 해제하지 않는다. 스크롤 입력을 가로채지 않는다. ‘장면으로 보기’는 같은 공간의 정지 이미지 다섯 장으로 전환한다. `prefers-reduced-motion` 사용자는 처음부터 이 모드로 들어온다. 사용자가 모드를 직접 선택하면 그 선택을 존중한다.

객실 상세는 별도 페이지 이동 없이 열린다. Escape 또는 닫기 버튼으로 닫으면 여정 위치와 버튼 초점을 복구한다. 예약, 결제와 외부 전송은 제공하지 않는다.

## 실행

저장소 루트의 HTTP 서버로 연다.

`http://127.0.0.1:8770/16-seam-hotel/#arrival`

HTML, CSS, JavaScript와 로컬 자산만 사용한다. 빌드 과정과 CDN 의존성은 없다. 소스를 파일로 직접 열면 프레임 fetch가 제한될 수 있으므로 HTTP로 실행한다.

## Flow 실사 시험 버전

`http://127.0.0.1:8770/16-seam-hotel/flow.html#room`

기존 3D 여정은 그대로 유지하며, 별도 `flow.html`에서 두 번째 Google Flow 결과만 표시한다. 객실, 빛, 문턱, 테라스, 바다의 다섯 구간은 하나의 8초 촬영 이동을 나눈 것이다. 접근로와 로비가 새로 촬영된 영상이라는 뜻은 아니다. 360p AI 시험 영상으로, 원래 호텔의 의자와 해안 배치가 달라져 엄격한 동일 공간 기준은 아직 실패다. 영상 자체의 전체 연속 모션 검수와 최종 해상도 검수도 미완료이며, 완성 미디어로 승격하지 않는다.

원본의 192프레임, 24fps를 자르지 않고 WebP로 변환해 동일한 스크롤 프레임 렌더러에 연결한다. 무음 MP4와 영상의 워터마크를 보존하며 업스케일링이나 워터마크 제거는 하지 않는다. 세로 화면에서는 같은 프레임을 화면 비율에 맞춰 보여주므로 일부 주변부가 잘린다. 생성 비용을 추가로 사용하지 않는다.

이번 웹 연결의 통과 조건은 1280×720, 390×844에서 화면 전체를 채우고, 전진과 역방향 스크롤의 프레임 번호가 같은 방향으로 바뀌며, 멈추면 동일한 프레임을 유지하는 것이다. 다섯 장면 이동, 정지 이미지 모드, 객실 상세 열기와 닫기, 320×568의 버튼 겹침과 넘침도 확인한다. 서체는 기존 MaruBuri Light 제목, Pretendard UI와 본문, Georgia 영문 브랜드를 그대로 재사용한다. 기존 라이선스와 배포본은 `SOURCES.md`를 따른다. 웹 동작 검수와 생성 영상의 품질 판정을 구분한다.

## 미디어 재현

`tools/build_scene.py`가 건축, 가구, 조명, 식재와 카메라 동선을 만든다. Blender 5.2.1 LTS를 사용했다. `--preview`는 대표 장면, `--animate`는 전체 프레임을 렌더링한다. `--output`에는 Desktop 검수 작업 폴더의 절대 경로를 준다. PNG 원본을 웹 폴더에서 렌더하지 않는다.

`tools/export_media.py`는 Pillow와 FFmpeg로 포스터, 프레임 WebP와 MP4를 만든다. 출력은 이 사이트의 `assets/`다. 원본 PNG와 카메라 동선 기록은 지정한 검수 작업 폴더에 보존한다.

## Flow 24초 전체 여정

`http://127.0.0.1:8770/16-seam-hotel/flow-journey.html#arrival`

같은 가상 호텔의 새 사진형 AI 영상이다. 접근로, 중정, 로비 회전, 열린 문을 통한 객실 진입, 열린 테라스 통과를 네 생성 구간으로 연결한다. 앞선 3D와 8초 시험은 보존한다. 720p 생성의 무료 1080p 업스케일을 사용하며, 실제 26초 이동을 균일하게 약 8.33% 빠르게 편집한 24초 영상이다. 무음 MP4와 576개 원본 비율 WebP를 같은 스크롤 렌더러에 연결한다.

전체 화면의 네이티브 스크롤 위치가 프레임을 결정한다. 다섯 장면 직접 이동, 같은 소스의 정지 사진 보기, 객실 상세와 닫기 복귀를 제공한다. 세로 화면은 동일 프레임을 화면에 맞춰 자르며 카메라 이동 단계에 따라 열린 문과 침대 쪽 구도를 조정한다. 1920×1080 디코드 캐시는 데스크톱 12개, 800px 미만 6개다. 동시 인접 요청은 각각 7개와 4개로 제한한다.

`tools/export_flow_journey.py`는 실제 소스 0-8, 0-6, 0-6, 0-6초 선택, 균일 13/12 속도, 24fps 576프레임 MP4와 WebP를 재현한다. FFmpeg, FFprobe와 Pillow가 필요하다. `--source-dir`에는 SOURCES의 원본을 보존한 Desktop 작업 폴더를 지정하며 `--web-only`는 검증한 MP4를 그대로 다시 변환한다. 원본 소스는 덮어쓰지 않는다.

2026-10-04 실제 최종 편집본의 전체 0-24초를 겹치는 10초 구간 0-10, 8-18, 14-24로 나누어 연속 모션을 검수했다. 모든 연결부가 검토 구간 내부에 포함된다. 도구 보조 검수와 실제 연결부 프레임 대조에서 전체 물리 동선, 공간 정체성과 외부 테라스 끝점이 통과했다. 도구의 한 번에 10초 첨부 제한을 넘어 전체를 보았다고 주장하지 않는다. 작은 재질의 AI 질감 떨림은 남는다.

로컬 인앱 브라우저 1280×720과 390×844에서 전진 0→77, 정지 77 유지, 역행 77→38을 확인했다. 다섯 장면 0, 121, 259, 437, 575, 정지 사진 모드, 상세 닫기와 기존 프레임 및 버튼 초점 복귀도 확인했다. 마지막 소스에서 1280×720 다섯 스크롤 장면도 실제 표시 프레임까지 도달한 뒤 검수했다. 모바일 로비의 객실 입구가 화면 가장자리로 밀리는 문제를 수정해 문을 중심에 보이게 했다. 검사한 새 주요 버튼과 장면 링크의 조작 영역은 가로와 세로 44px 이상, 가로 넘침은 0이며 브라우저 경고와 오류는 없었다.

공통 코드 변경 후 기존 3D는 481프레임, 기존 Flow는 192프레임 소스를 유지하고 각각 0→64, 0→42 전진이 정상이다. 새 경로의 실기기 Safari, 화면 읽기 도구, OS 모션 줄이기 설정, 느린 네트워크와 공개 배포는 미검증이다. 검수 캡처와 운영 기록은 SOURCES에 연결한 Desktop 제작 작업 폴더에 있다.

이 경로는 AI로 만든 가상 호텔 포트폴리오다. 실제 촬영, 실제 호텔 예약과 공개 운영을 나타내지 않는다. 상세 생성 출처, 소비와 질감 한계는 SOURCES를 따른다.


## 2026-10-04 시각 개편 기준 v1

사용자 요청은 좋은 레퍼런스 하나를 선정해 기존 Flow 24초 여정의 카피, 서체, 아이콘과 타이포 모션을 개선하는 것이다. 대상은 flow-journey.html과 객실 상세이며 실제 스크롤과 원본 영상, 다섯 장면의 순서를 유지한다. 기존 사진형 화면을 시각 기준으로 사용하고 Product Design의 기존 경험 검수, 웹 가이드와 카피 작성 기준을 함께 적용한다.

레퍼런스는 https://thelargo.com/ 의 실제 1280×720 첫 화면과 본문이다. 전폭 사진, 가는 세리프와 이탤릭, 사진을 가리지 않는 여백, 적은 수의 명확한 행동을 차용한다. 브랜드, 문구, 사진과 수채화 자산은 복제하지 않는다. 기존 SEAM에서는 반복된 제목 등장 방식, 작은 보조 문구와 숨은 장면 이름, 문자 기호 아이콘의 불균일한 굵기를 개선 대상으로 관찰했다.
