# Formkey

사용자가 고른 Raycast를 참고한 업무용 생산성 도구의 메인 1페이지 포트폴리오다. 가상 브랜드 Formkey의 제품 소개와 검색, 메모, 집중 타이머를 브라우저 안에서 시연한다. 기존 포트폴리오의 정적 HTML/CSS/JS 구조를 사용한다.

## 채택한 디자인 기준

- Raycast 현재 메인의 1280×720과390×844, 전체 본문, 모바일 메뉴 및 Design 기능 탭을 직접 캡처했다. 원본은 `$HOME/Desktop/codex-output/99_최종아님_삭제대기/raycast-formkey-20261008/source/`에 있다.
- 검은 배경과 붉은 입체 이미지, 중앙의 큰 영문 제목, 떠 있는 얇은 경계선의 헤더를 유지한다. PC 헤더는 좌우38px/위16px/높이76px, 모바일은 좌우16px/높이59px다.
- 영문 제목과 주요 제목은 Space Grotesk600, PC64px/행간1.08,390px35px,320px29px이다. 원본을 기준으로 잡은 위계에 사용자가 요청한 기술적인 서체 개성을 더했다. 제품 UI와 본문은 기존 Inter를 유지한다. 한글 설명과 UI는 Pretendard를 대체 서체로 명시한다. 서체 바이너리와 라이선스를 로컬 배포한다.
- 원본의 제품 화면, 분야별 카드, 반복 작업 패널과 마무리 CTA 흐름을 가져온다. PC1204px 본문, 모바일16px 여백 및 한 열/가로 카드 탐색을 사용한다.
- 검색 결과와 선택, 메모 입력/유지, 타이머 시작/정지/초기화, 문장 복사, 기능 탭, 모바일 메뉴와 팀 문의 시연은 실제 브라우저에서 검수한다. 내부 그림/도형으로 만든 가짜 이미지 대신 자체 생성한 두 래스터와 정식 라이선스 아이콘을 사용한다. 제품 창과 단축키는 실제 동작하는 HTML UI다.
- 원본의 브랜드/로고/사용자 얼굴/고객 후기/성과 수치/제3자 연동 주장/다운로드와 결제는 재현하지 않는다. Formkey만의 문구와 자산을 사용한다. 이 차이는 포트폴리오용 의도한 조정이다.
- 첫 화면은 붉은 래스터의16초 이동, 회전과 확대 루프, 제목과 버튼의 순차 등장 및 포인터 반응을 사용한다. 텍스트는 등장 후 고정한다. 첫 화면과 푸터에서 같은 모션 상태를 조절하며 일시 정지 시 이미지를 현재 프레임에 멈춘다. 화면 밖이나 비활성 탭에서는 배경 애니메이션을 쉬고, prefers-reduced-motion에서는 정적 화면을 제공한다.
- 1280×720와390×844에서 원본과 함께 비교하고320px도 확인한다. 모든 주요 컨트롤이 가리지 않고 가로 넘침 없이 사용돼야 한다. 개인정보와 입력은 외부 전송하지 않는다.

## 실행

상위 저장소의 기존 미리보기 서버를 사용한다. `http://127.0.0.1:8786/18-formkey-productivity/`를 연다. 자산 출처는 `assets/SOURCES.md`, 실제 검수는 `design-qa.md`를 따른다. 새 공개 배포와 기존 브랜드 홈페이지의 사본 동기화는 이번 제작 범위에 포함하지 않는다.
