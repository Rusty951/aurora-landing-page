# 전문직 웹사이트 포트폴리오

기존 의료 6개·일반 업종 6개와 별도로 추가한 독립적인 정적 웹사이트 2개다.

- `../13-chaon-law/`: 차온 법률사무소. 상황별 업무 탐색, 첫 상담 준비, 체크리스트.
- `../14-gyeoldam-registry/`: 결담 법무사사무소. 등기 분야·업무 선택, 준비 정보, 진행 안내.
- `base.css`, `ui.js`: 메뉴·대화창·키보드 포커스·FAQ 기반 접근성만 공유한다. 첫 화면·본문 구조·브랜드 스타일은 각 디렉터리에서 관리한다.

## 로컬 실행

저장소 루트에서 `python3 -m http.server 8765 --bind 127.0.0.1`를 실행한다. 이미 같은 서버가 실행 중이면 다시 실행할 필요가 없다.

- 허브: http://127.0.0.1:8765/
- 차온: http://127.0.0.1:8765/13-chaon-law/
- 결담: http://127.0.0.1:8765/14-gyeoldam-registry/

모든 사업체·주소·번호는 가상이다. 전화 링크·외부 전송·실제 예약·서류 업로드·저장 기능이 없다. 상담 시연과 확인 표시는 페이지 메모리에서만 동작하고 새로고침하면 초기화된다. 법적 제출 요건·개별 판단·기한·실적·자격·후기는 제시하지 않는다.

각 `assets/SOURCES.md`에 사진 출처·사용권과 공식 정보 참고 범위를 기록했다. 사진은 교체하기 쉽게 각 사이트의 `assets/`에 보관한다. 마루 부리와 Pretendard 웹폰트는 라이선스와 함께 로컬 fonts/에서 불러온다. 이 두 사이트는 외부 글꼴 서버 연결 없이 같은 글꼴을 사용한다. 공개 배포 설정은 없다.

메뉴는 모바일에서 포커스 순환과 Escape 닫기를 제공한다. native dialog는 배경 포커스를 제한하고 닫으면 열었던 버튼으로 복원한다. 차온 탭은 데스크톱 세로 목록·모바일 가로 목록으로 재배치하며 위/아래 및 좌/우 방향키, 결담 탭은 좌/우 방향키 및 Home/End로 이동한다. 현재 두 사이트는 즉시 이동을 사용하며 자동 애니메이션은 없다. `prefers-reduced-motion` 규칙도 유지한다. 차온의 메뉴는 스크롤 후에도 화면 위에 남는다.

첫 화면의 사진·타이포그래피, 본문 순서와 연락 안내는 각 사이트에서 독립적으로 설계한다. Lucide 아이콘 원본과 LICENSE-LUCIDE를 이 디렉터리에 함께 보관한다.

타이포그래피는 typography.css, 브랜드별 세부 표현은 각 사이트의 refinement.css에서 관리한다. 기존의 독립적인 업무 탐색·준비 정보와 시연 동작은 유지한다.
